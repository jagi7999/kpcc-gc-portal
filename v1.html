Create Role / Add Account

Preload State & District Committee Data

Loads the KPCC Graduate Cell State Committee (30 members) and District Presidents list (30 districts) from the source documents — 56 members in total, each with an auto-generated office-bearer login and a personal dashboard login for document upload. Safe to click more than once: anyone whose mobile number already exists is skipped.

If you already loaded committee data earlier, the State President may have ended up with 2–3 separate logins (a Karnataka State office-bearer login, the State Panel login, and a personal member login). Click the fix button to remove the extras and keep only the one State President login — he's the leader for everyone, so one credential is enough.

Quick-Add Member (no documents yet)
